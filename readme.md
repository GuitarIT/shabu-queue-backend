# Implementation Plan: ระบบจองคิวร้านชาบูอ้วนกลม

## 1. Project Overview

สร้างเว็บ **ระบบจองคิว (Queue Booking System)** สำหรับเจ้าของร้านชาบูอ้วนกลมและลูกค้า

## 2. Technology Stack

* Frontend: HTML + CSS + Bootstrap + JavaScript
* Backend: GO
* Database: MySQL / MariaDB
* Owasp Top 10

---

## 3. User Roles

### Admin (เจ้าของร้าน/พนักงาน)

* สร้าง/แก้ไขรอบคิวและโต๊ะว่าง
* อัปเดตสถานะคิว (เรียกคิว/เข้าทานแล้ว)
* เพิ่ม/ลบคิว (กรณี Walk-in หรือลูกค้าไม่มา)
* สร้าง/แก้ไข/ลบ ประกาศโปรโมชั่น
* ดูรายชื่อลูกค้าที่จองคิว
* คืนโต๊ะว่างเข้าระบบ: สามารถกดเปลี่ยนสถานะคิวเป็น ทานเสร็จ (completed) เมื่อลูกค้าเช็คบิลก่อนเวลา
* ระบบแจ้งเตือนคิวล่าช้า: หากลูกค้ามาเลทเกินเวลาจอง 5 นาที แถวของคิวนั้นบน Dashboard จะเปลี่ยนสีอัตโนมัติ และแสดงข้อความ (ทำงานผ่าน JavaScript)เพื่อให้ Admin ตัดสินใจจัดการเรียกซ้ำหรือกดยกเลิกคิว

### Customer (ลูกค้า)

* ดูรอบคิวและโต๊ะที่ว่าง
* ดูประกาศโปรโมชั่น
* จองคิว (Booking)
* ยกเลิกคิวของตนเอง
* ดูสถานะคิวปัจจุบันของตนเอง

## 4. Core Features

### Authentication

* Register
* Login
* Logout
* Password Hashing
* Session Management

### Booking (การจองคิว)

* Create (สร้างการจองคิว)
* View (ดูรายละเอียดคิว)
* Edit (แก้ไขจำนวนคน/เลื่อนเวลา)
* Delete (ยกเลิกคิว)
* View Queue Status (ดูสถานะคิวว่าถึงคิวที่เท่าไหร่แล้ว)
* Fixed Time Slots: บังคับให้จองผ่านปุ่มรอบเวลาที่กำหนดไว้เท่านั้น (เช่น ทุกๆ 10 นาที) เพื่อลดความผิดพลาดในการกรอกข้อมูล
* Overbooking Prevention: คำนวณระยะเวลาทานแบบสมจริง (Time Overlapping) โดยนับเฉพาะโต๊ะที่ลูกค้ากำลังนั่งทานอยู่จริงในเวลานั้น เพื่อป้องกันคิวเต็มหรือซ้อนทับกัน
* Validation (การตรวจสอบความถูกต้อง)
* ป้องกันการจองรอบเวลาย้อนหลังสำหรับวันปัจจุบัน โดยระบบจะปิดการทำงาน (Disable) ปุ่มเลือกรอบเวลาที่ผ่านไปแล้วอัตโนมัติ
* ฝั่ง Backend (Go) จะมีการตรวจสอบซ้ำอีกครั้งก่อนบันทึกลงฐานข้อมูลเพื่อป้องกันความผิดพลาดหรือการดัดแปลงข้อมูลจากหน้าเว็บ
### Dashboard

Admin:

จำนวนคิวทั้งหมดของวันนี้
จำนวนโต๊ะที่ว่าง
คิวที่รอเรียก
คิวที่ให้บริการเสร็จแล้ว

Customer:

จำนวนคิวที่รออยู่ข้างหน้า
ประวัติการจองคิวที่ผ่านมา
สถานะคิวปัจจุบัน

## 5. Suggested Database

users
- id
- name
- phone_number
- password_hash
- role

announcements
- id
- admin_id
- title
- content
- created_at

bookings
- id
- customer_id
- pax_count (จำนวนลูกค้าที่มาทาน)
- booking_date
- booking_time
- end_time
- status (waiting, seated, cancelled)
- created_at

Relationship หลัก:

Users (ตารางผู้ใช้งานระบบ)
  |
  |___ Admin (เจ้าของร้าน)
  |      |
  |      |___ Announcements (สร้างและจัดการประกาศโปรโมชั่น)
  |      |___ Bookings (ดูคิวทั้งหมด และอัปเดตสถานะคิว เช่น รอคิว, เข้าทาน, ทานเสร็จ, ยกเลิก)
  |
  |___ Customer (ลูกค้า)
         |
         |___ Bookings (จองคิว และจัดการได้เฉพาะคิวของตนเองเท่านั้น)
